# Parcel Cloudflare 部署：当前状态与验收范围

更新日期：2026-10-20（Asia/Shanghai）。当前公开源码位于仓库 `main`，线上使用 Workers + D1 + 私有 R2。管理员通过密码 + TOTP 登录，文件在上传者浏览器加密，接收者浏览器解密并流式保存。部署操作以 [v3-deployment.md](v3-deployment.md)和[图文教程](https://parcelwiki.pages.dev/zh)为准。

## 已上线功能

- 管理员密码 + TOTP，扫码或手动绑定、恢复码、更换认证器、会话与持久化限流。
- AES-256-GCM 分块加密，密钥信封、完整链接片段、独立在线密码凭据及加密密钥备份。
- 完整文件 SHA-256 核对、上传暂停与重选续传、密文 IndexedDB 接收恢复与流式解密保存。
- D1 原子配额和下载资格，首次响应丢失后幂等恢复，同一有效会话重试与续签不重复扣次。
- 有限或不限次数分享、过期与撤销、R2 删除确认后的配额释放、Cron 恢复清理。
- 发布前 D1 migrations，保留现有生产资源、运行时变量与 Secrets 的 Git 自动部署。

## 2026-10-20 验收

加密核心、workerd/D1/R2、部署迁移工具、登录响应恢复与浏览器回归均已通过。真实 HTTPS 套件覆盖 Chromium、Firefox 与移动端 Chromium 模拟，实际使用浏览器存储、Service Worker 和浏览器下载，不以路由拦截替代保存路径。

本地真实 HTTPS + D1/R2 夹具完成 **8 GiB** 全流程：上传响应丢失、刷新重选续传、下载资格响应丢失、密文缓存恢复、签名 URL 失效续签，以及真实浏览器流式保存。最终完整 SHA-256 与原文件一致，同一下载资格只计一次。

线上实际 R2 验收使用约 **16 MiB 的多分块演示文件**，完成浏览器加密上传、真实密文 Range 下载、流式解密保存与完整 SHA-256 比对；刷新保留缓存，下载计数为一次。演示分享已撤销。此结果不等于线上完成了 8 GiB 上传，也不等于所有手机或无痕环境均能保存大文件。

中英文教程已核对 TOTP 单一流程、三段式加密图、原尺寸无损脱敏截图、配置生成器及桌面/平板/手机排版，线上公开文件与提交内容逐项校验一致。旧标签页须刷新才能加载发布后的静态页面。

## 边界与升级

旧未加密 Worker 分享需要保留原文件后重新上传；迁移不自动加密或清空旧数据。新版 E2EE 分享不能导出为 Go 可读分享。管理员凭据、服务端 Secret、D1/R2 备份与浏览器文件密钥备份分别保管，不能相互替代。

独立 Go/Origin 代码与历史验收记录继续保留其原协议范围，不代表支持当前 TOTP 或 E2EE。后续变更须继续验证密钥、完整性、恢复、计数和真实浏览器保存；生产 CPU、CORS、签名、清理及实际设备限制仍需线上观察。
