# 真实局域网设备验收

> 适用范围：本文件是独立 Go/SQLite 兼容程序的维护资料或历史记录，不描述当前 Cloudflare 部署。当前密码 + TOTP、文件端到端加密及部署操作见 [Cloudflare 部署说明](v3-deployment.md)；不要据此推断 Go 已具备这些功能。

此项需要一台局域网电脑和一部真实手机；Pi 上的浏览器模拟不能替代。用户已确认第二台电脑可访问新建分享页，手机与完整闭环仍待执行。下面是可直接按顺序完成的步骤。

## 准备

电脑和手机连接能访问 `192.168.5.16` 的局域网。分别打开 `http://192.168.5.16:8080`，确认出现 Parcel 登录页。若只有一个设备能打开，先记录设备、网络和错误，不把它标为通过。

管理员初始密码保存在 Pi 的 `/home/hyphy/gitcode/Parcel/.parcel-local/admin-password`，未提交到 Git。分享密码与管理员密码是两种凭证；不要把密码或完整分享/下载地址写进验收反馈。

## 电脑上传、手机接收

1. 电脑登录，选择一个普通文件，最好包含中文文件名；设置有效期 1 小时、下载次数 1，并开启分享密码。等待校验完成，得到链接。
2. 手机打开该链接。未输入密码时，页面不应显示文件名及大小；错误密码应有提示，正确密码后才能显示文件信息。
3. 手机上下载并确认文件已保存，文件名、大小或实际打开的内容与原文件一致。下载过程查看手机浏览器的下载列表。
4. 电脑的分享详情应显示已使用 1 次资格。在手机原接收页再次点击下载，同一有效票据重试后仍为 1 次；不要刷新该接收页。
5. 用新的浏览器标签页打开分享链接。次数已用完时不能取得新的下载资格；若页面要求密码，解锁后同样不能新下载。
6. 电脑撤销分享。手机刷新接收页后应显示不可下载，原下载按钮也不能发起新的有效下载。

## 手机上传、电脑接收

1. 手机回到首页登录管理员，选择手机中的普通文件或照片，创建一个新分享，下载次数设为 3。
2. 上传完成并经过校验后，使用复制按钮取得链接；在内网 HTTP 中会尝试兼容复制；若浏览器拒绝所有复制方式，应出现可以选择并手动复制的文本。
3. 电脑打开链接并下载，确认文件名及内容正常。
4. 手机管理页能看到该分享的计数，并能撤销；电脑刷新接收页后不可再下载。

## 记录结果

可以按下面的格式反馈文字。未执行的项填“未测”，不要凭界面出现下载按钮就确认文件已经保存。

```text
电脑：系统 / 浏览器及版本
手机：型号 / 系统 / 浏览器及版本
网络：普通局域网 Wi-Fi、有线或其他
两台设备都能打开首页：通过 / 失败
电脑上传 → 手机保存文件：通过 / 失败
密码与元数据保护：通过 / 失败
原页面重试仍计 1 次，新页面不能新下载：通过 / 失败
撤销后不可再下载：通过 / 失败
手机上传 → 电脑保存文件：通过 / 失败
手机复制或手动复制链接：通过 / 失败
失败现象及发生步骤：
```

本流程验证真实设备的基本闭环。自动上传恢复、Range 协议、崩溃恢复、磁盘故障及并发计数已有独立测试；手机浏览器是否自动续传仍取决于浏览器，不能从这份基本闭环记录推断。
